# V1.8.0 发布说明

## 新增与修复

- 普通成员可使用原密码自由修改密码。
- 新增登录页忘记密码七阶段流程：查询、申请、待审批、批准重置、拒绝、申诉和重新审批。
- 密码恢复凭据绑定发起申请的浏览器，并通过 HttpOnly Cookie 保存；申请和申诉进入消息中心，不混入采购待审批。
- 角色名称统一为“审批与危险采购人”，并提供独立待审批入口。
- 强制两阶段规则：所有加急申请先由老师（超级管理员）审批；加急危险品通过后再进入危险品复核；普通危险品由审批与危险采购人审批。
- 为 2 核、4 线程、6 GB 服务器优化实时刷新、库存搜索、SQLite 和静态资源缓存，并限制大列表响应。

## 验证

- 52 个测试文件、183/183 项测试通过。
- TypeScript/lint、生产构建和完整 acceptance 通过。
- 当前开发机性能基准通过：三个主要端点 p95 均低于 20 ms，20 并发请求零错误，RSS 约 98.5 MB。
- 性能数据是开发机回归基线，不代表目标服务器等效性能。
- V1.8.0 没有独立 DSH 审查原件；V1.7.0 的审查结论不外推到本版本。

## 远程迁移到本地

不要在线复制整个服务器目录。正确流程是：

1. 暂停用户操作并停止远程应用；
2. 备份 `.env` 和整个 `data/` 目录；
3. 在本地从 GitHub/Release 重新部署程序；
4. 恢复 `.env` 和 `data/`；
5. 校验哈希、健康接口和业务数据；
6. 本地稳定运行后再关闭远程服务器。

详见 [`docs/REMOTE_TO_LOCAL_MIGRATION.md`](https://github.com/lunncing/lab-chemical-manager/blob/v1.8.0/docs/REMOTE_TO_LOCAL_MIGRATION.md)。

## 升级注意

升级前必须停止旧服务并备份整个 `data/`。真实数据库、`.env`、账号和消息不会上传到 GitHub。公网部署仍需 HTTPS、反向代理、登录/注册限流和云安全组限制。
